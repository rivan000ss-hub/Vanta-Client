# VANTA Client

A lightweight Minecraft Java launcher prototype for Minecraft 1.21.11.

## Features
- Installs Fabric Loader
- Installs Fabric API and Sodium
- Dark, minimalist launcher interface
- Windows build workflow via GitHub Actions

## Build
Run `build_windows.bat` on Windows, or use the GitHub Actions workflow to build the Windows executable.

The current prototype opens the official Minecraft Launcher when Play is clicked. Microsoft sign-in and direct game launching are planned for a future version.
