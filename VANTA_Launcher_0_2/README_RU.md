# VANTA Launcher 0.2

Тёмный игровой лаунчер Minecraft Java Edition. Это ранний функциональный прототип.

## Что умеет текущая версия
- Интерфейс с разделами «Главная», «Установка» и «Настройки».
- Установка Fabric Loader для Minecraft 1.21.11.
- Загрузка совместимых Fabric API и Sodium из Modrinth.
- Отображение хода установки и журнала действий.
- Проверка Java и наличия профиля Fabric.
- Открытие папки .minecraft.
- Открытие официального Minecraft Launcher.

## Что пока не реализовано
- Собственная авторизация Microsoft.
- Прямой запуск Minecraft из VANTA без официального лаунчера.
- Управление несколькими игровыми профилями.

Кнопка «Запустить» открывает официальный Minecraft Launcher и предлагает выбрать установленный профиль Fabric. Если профиль не найден, VANTA предложит перейти к установке.

## Требования
- Windows 10/11 x64.
- Java 21 x64 для установки Fabric.
- Официальный Minecraft Launcher и лицензия Minecraft Java Edition для игры.

## Использование готовой сборки
1. Скачай ZIP-артефакт из GitHub Actions.
2. Извлеки архив полностью.
3. Открой папку VANTA-Launcher.
4. Запусти VANTA-Launcher.exe. Не отделяй EXE от файлов и папок рядом с ним.

## Локальная сборка
1. Установи Python 3.12 x64 с поддержкой Tcl/Tk.
2. Открой папку проекта.
3. Запусти build_windows.bat.
4. Готовая папка приложения появится в dist\VANTA-Launcher.

## Автоматическая проверка
GitHub Actions проверяет синтаксис Python, собирает Windows-пакет и запускает --self-test. Самотест проверяет загрузку Tcl/Tk, создание всех страниц интерфейса и наличие обработчиков у кнопок.
